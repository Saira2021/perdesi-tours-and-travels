# Perdesi Tours: Pakistan's Northern Gems

Website: [perdesitours.com](https://perdesitours.com)

Website for Perdesi Tours, a woman-led travel agency offering tours of Pakistan's northern areas (Kalam, Hunza, Skardu, and more). Built with Next.js.

## Development

You need Node.js 22 (or 20.19+) — [install with nvm](https://github.com/coreybutler/nvm-windows).

```sh
nvm use 22.22.0
git clone <this-repository-url>
cd perdesi-tours-travels
npm i
npm run dev
```

Canonical URLs, Open Graph tags, and the sitemap use **https://perdesitours.com**. Set `NEXT_PUBLIC_SITE_URL` in `.env.local` if you need to override it.
